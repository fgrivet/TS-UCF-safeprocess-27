# TS-UCF: A Robust and Explainable Method for Time-Series Anomaly Detection

Official code for the **Safeprocess 2027** paper:
> *"TS-UCF: A Robust and Explainable Method for Time-Series Anomaly Detection"*

TS-UCF (**T**ime **S**eries **U**nivariate **C**hristoffel **F**unction) is a novel semi-supervised algorithm for **time series anomaly detection** based on **orthogonal polynomials**, and more specifically, on the (Univariate) **Christoffel Function**.
It combines **strong performance** with **interpretability**, addressing the common trade-off between "black-box" accuracy and over-simplified, interpretable models.

This repository contains the full implementation and all the code needed to **reproduce every result and figure** in the paper.

---

## Key Features

- **Frugal & easy to tune** — few hyperparameters, practical to deploy.
- **Multivariate support** — low-cost multivariate analysis by summing univariate
  window distances before applying the UCF.
- **Explainable** detections — anomaly scores derived from squared distances to
  reference windows via the Christoffel function. Dichotomy property of the UCF.
- **Impact score** — identifies the faulty variable(s) within a multivariate group.
- **Reproducible** — every figure and result from the paper is generated by the
  scripts in this repository.

## Quick Start

```python
from tsucf import TS_UCF

# Load your univariate (or multivariate) time series
signal_train = ...   # shape: (n, 1) or (n, d)
signal_test = ...    # shape: (n, 1) or (n, d)

# Init detector
detector = TS_UCF(n_min=1, n_max=10, L=100, keep_internals=True) # keep_internals=True mandatory for computing impact scores
# Fit
detector.fit(signal_train)
# Compute scores
scores = detector.decision_function(signal_test) # shape: (d+1, n_windows)

# Get the impact score for a multivariate group
impact = detector.impact_scores(sigma=0.1) # shape: (n_windows,)
```

A full usage example is available in: `notebooks/01_tsucf_demo.ipynb`

## Reproducing the Paper

All results and figures can be reproduced with a single command:

```bash
python scripts/reproduce_all.py
```

This will:
1. Download the benchmark datasets (`scripts/download_data.py`)
2. Run the anomaly detection experiments for all window sizes in the paper (`experiments/run_anomaly_detection.py`)
3. Run the impact score experiment (`experiments/run_impact_score.py`)
4. Generate all figures from the paper (`notebooks/02_figures.ipynb`)

### Individual steps

| Task                              | Command                                                                                             | Output                                                              |
| --------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Download data                     | `python scripts/download_data.py`                                                                   | `data/mTSBench` and `data/controlled-anomalies-time-series-dataset` |
| Run anomaly detection experiments | `python experiments/run_anomaly_detection.py --datafolder data/mTSBench --ws "auto"`                | `results/TS_UCF_{ws}_evaluation_results.csv`                        |
| Run impact score experiments      | `python experiments/run_impact_score.py --datafolder data/controlled-anomalies-time-series-dataset` | `results/impact_score_res.csv`                                      |
| Generate figures                  | `jupyter execute notebooks/02_figures.ipynb`                                                        | `figures/auc_roc_matrix.pdf` and `figures/vus_pr_boxplot.pdf`       |
